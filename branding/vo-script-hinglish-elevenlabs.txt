- Similarity: high is fine where you have it.
- Skip the audio tags ([laughs] etc.) for this one. It is a calm
  owner-to-owner read, not an emotive performance.

IF A WORD COMES OUT WRONG
You can mix scripts in the same line — swap just the broken word
to Devanagari and regenerate. Most likely troublemakers:

  kaagaz      ->  काग़ज़
  parchi      ->  पर्ची
  hisaab      ->  हिसाब
  raseed      ->  रसीद
  sambhaaliye ->  संभालिए
  baarah      ->  बारह
  intezaar    ->  इंतज़ार

Example fix:
  काग़ज़ sab bhool jaata hai.

Full Devanagari version of every line is in vo-script-hindi.txt
if you would rather run the whole thing in Devanagari — for Hindi
that usually gives cleaner pronunciation than romanized text.
